# Security policy

## Supported versions

Only the latest release of lateweave receives fixes.

## Reporting a vulnerability

Please report vulnerabilities privately, through
[GitHub security advisories](https://github.com/pau-mensa/lateweave/security/advisories/new),
not in a public issue. Include the version, the platform, and the smallest
input that shows the problem: a malformed store directory, for example, or a
query that reads outside the memory it should.

You should get an answer within a week. Once a fix is released, the advisory is
published with credit to the reporter, unless you prefer otherwise.
